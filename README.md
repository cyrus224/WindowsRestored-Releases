# Windows Restored releases

This public repository is the official download and update channel for Windows Restored.

It intentionally contains **release artifacts only**:

- Signed installers or portable packages
- SHA-256 checksums
- Signed update manifests
- Release notes and public usage documentation

Application source, project files, tests, debug symbols, build intermediates, and credentials must never be published here. Development source is maintained separately in a private repository.

There is no downloadable release yet. The application's update checker will remain inactive until the first release channel is configured.
